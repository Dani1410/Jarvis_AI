Asistente virtual inteligente diseñado para funcionar **100% Offline** en entornos Windows. Utiliza **Llama 3.2** para razonamiento y **ChromaDB** para memoria a largo plazo (RAG).

## 🚀 Características
- **Privacidad Total:** Todo corre en local (sin enviar audio a la nube).
- **Memoria Vectorial:** Recuerda datos persistentes usando RAG.
- **Control de Sistema:** Abre aplicaciones y ejecuta comandos de Windows.
- **Voz Neuronal:** Reconocimiento de voz con OpenAI Whisper.
